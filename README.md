# Municipal Data Scraper API

A micro-API built with FastAPI and Python to quickly extract official municipal data by ZIP Code. This API handles resolving ZIP codes to city/state, finding the official municipal/town website using Wikipedia/Search heuristics, and parsing the HTML for key contact information and relevant civic links.

## Overview
Scraping local government websites is notoriously difficult because every county and town uses a different CMS or HTML structure. 
This micro-API acts as a simple wrapper. You provide a ZIP code, and the API automatically locates the official municipal website and extracts highly relevant structured data, including:
- City Council Member lists
- Board of Zoning / Planning Boards
- Meeting Minutes and Agendas
- Mayor's Office Contacts
- Official municipal phone numbers

## Tech Stack
- **Framework**: FastAPI
- **Scraping**: BeautifulSoup4, Requests
- **Resolution**: Zippopotam.us API, Wikipedia API (as a highly reliable fallback for datacenter IP ranges)
- **Deployment**: Render (configured via `render.yaml`)

## Local Development

1. Create a virtual environment and install dependencies:
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

2. Start the local server:
```bash
uvicorn main:app --reload
```

3. Open `http://localhost:8000/docs` in your browser to view the interactive Swagger UI and test the `/scrape` endpoint.

## Deployment
This project is configured to be deployed easily on [Render](https://render.com/). 
Simply connect this repository to a Render Web Service. The `render.yaml` file will automatically configure the environment, build command, and start command.

## Monetization
This API is designed to be hosted on Render and monetized through [RapidAPI](https://rapidapi.com/). The `/openapi.json` generated by FastAPI can be directly imported into RapidAPI Studio to auto-generate the endpoint documentation.
